Cheat Sheet / Reference · Lesson 0002

CKA 考場搶分神技：kubectl 盲打與極速排錯速查表

CKA 考試 2 個鐘做 17 題，每一題都係實戰。手寫 YAML 絕對係死路一條！呢份 Cheatsheet 教你點樣用 --dry-run=client -o yaml 配合萬能 Alias，5 秒鐘生出乾淨 YAML！

1. 考場必設 3 大神級 Alias (開考首 60 秒做)

# 1. 縮寫 kubectl 變成 k
alias k=kubectl

# 2. 自動補全 (Auto-completion)，按 Tab 鍵補全 resource 與 pod 名字
source <(kubectl completion bash)
complete -o default -F __start_kubectl k

# 3. 5 秒生成 YAML 模板神器
export do="--dry-run=client -o yaml"

# 4. 強制秒殺 Pod (唔洗等 30 秒 graceful shutdown)
export now="--force --grace-period=0"

2. 5 秒 Imperative 指令生 YAML 對照表

目標資源 極速 Imperative 指令 (配合 $do) 產出重點
Pod k run my-pod --image=nginx $do > pod.yaml 最純淨嘅單個 Pod 結構
Pod (帶 Port/Env) k run my-pod --image=nginx --port=80 --env="ENV=prod" $do > pod.yaml 自動填好 ports 同 env block
Deployment k create deploy my-dep --image=nginx --replicas=3 $do > dep.yaml 包裝好 spec.template 同 matchLabels
Service (ClusterIP) k expose pod my-pod --port=80 --target-port=80 $do > svc.yaml 自動綁定 Pod 嘅 labels 做 selector
Service (NodePort) k create svc nodeport my-svc --tcp=80:80 $do > svc.yaml 自動設定 NodePort 類型
Namespace k create ns test-ns $do > ns.yaml 極速生成 namespace definition
ConfigMap k create cm app-config --from-literal=APP_MODE=prod $do > cm.yaml 免手寫 Key-Value
Secret k create secret generic app-secret --from-literal=dbpass=p@ss123 $do > sec.yaml 自動轉成 Base64

3. CKA 排錯 4 部曲 (救命順序)

  1. k get pods -A -o wide ➜ 睇邊個 Pod status 有古怪，同埋佢分配喺邊粒 Node。
  2. k describe pod <pod-name> ➜ 碌到最底睇 Events:（90% 嘅報錯如 ImagePullBackOff、OOMKilled、FailedScheduling 都喺度寫得一清二楚）。
  3. k logs <pod-name> [-c container-name] [--previous] ➜ 睇 Container 崩潰時吐出嘅 stderr/stdout。加 --previous 可以睇上一次死咗嗰個 Container 嘅遺言！
  4. k exec -it <pod-name> -- sh (或 bash) ➜ 入容器內部做 curl 或網絡偵測。
