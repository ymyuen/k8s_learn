Lesson 0002：Deployment、自我修復與 Rollout/Rollback

目標：上一課你用 kubectl run nginx 跑出粒裸 Pod——刪走就真係冇咗。今課只做一件事：學識用 Deployment 包住 Pod，等「Pod 死咗自己生返」變成理所當然，再加埋考場 5 秒出 YAML 神技。

1. 控制器思維：期望狀態 vs 現況

記返 0001 心法——你宣告「想要咩」，K8S 負責「變成嗰樣」。Deployment 就係呢個心法第一次完整落地：

Reconcile loop（調節迴圈）
你宣告：我要 3 粒 nginx Pod
 ↓ 寫入 etcd（期望狀態）
控制器不斷對數：而家有幾粒？
  ├─ 有 3 粒 → 咩都唔使做
  ├─ 得 2 粒 → 即刻補 1 粒   ← 呢個就係「自我修復」
  └─ 有 5 粒 → 斬走 2 粒

呢個迴圈由 kube-controller-manager 入面嘅控制器執行（見 詞彙表 Controller）。自癒唔係魔法，就係一道不斷對數嘅迴圈。

2. Deployment 三層結構（排錯全靠佢）

Deployment 唔直接管 Pod，佢經 ReplicaSet 間接管。記住呢張表：

層級負責咩一個比喻（港式職場版）
Deployment 管「版本」：滾動更新、回滾、期望副本數 發行負責人：決定而家出邊一版
ReplicaSet 管「數量」：確保 N 粒 Pod 同時存在 排更主管：確保隨時有 3 個人返工
Pod 管「容器」：實際跑應用 前線員工：真正落手做嘢嗰個

Deployment 點「認領」自己嘅 ReplicaSet 同 Pod？靠 Label & Selector——Deployment 用 selector 揀中佢嘅 ReplicaSet，ReplicaSet 再用 selector 揀中佢嘅 Pod。細節留返 0003，今課記住一句：「邊個管邊個，靠標籤認人，唔靠名」。

裸 PodReplicaSetDeployment
刪 Pod 會點刪咗就冇，唔會返生即補返粒，保持副本數經 ReplicaSet 即補返粒
換 image 點換要刪咗再起（斷線）要人手逐粒換，無 rolling 策略set image 即 rolling，新舊並存逐粒換
回滾得唔得唔得，舊 Pod 已刪唔得，唔記版本得，rollout undo 即返上一版
有冇版本號冇冇（得 template hash 分新舊）有，REVISION 1、2、3… 咁數上去

一句記：裸 Pod 係散工、RS 係排更、Deployment 係出版本＋留歷史嗰個。

⚡ 考場 5 秒出裝工作流（Imperative 生 YAML）

開考首 60 秒必設：alias k=kubectl ＋ export do="--dry-run=client -o yaml" ＋ bash completion。之後所有 kubectl create … $do 即刻吐 YAML。

3. 實作 A：自我修復（親眼見一次就明）

喺你個 kind 叢集（單節點都夠用）開個 terminal 照打：

將 3 粒 nginx Pod 變成 Deployment
# 1. 起 Deployment，期望 3 個副本
kubectl create deployment nginx --image=nginx:1.25 --replicas=3

# 2. 一次睇三層（deployments, replicasets, pods）
kubectl get deployments,replicasets,pods

# 3. 特登斬走一粒 Pod——記住佢個名（隨機尾碼）
kubectl delete pod nginx-(隨機尾碼)

# 4. 再 list 一次：總數維持 3 粒，但尾碼換咗＝「新嘅一粒」
kubectl get pods

# 5. 睇 Deployment 事件——會見到 ReplicaSet 重建紀錄
kubectl describe deployment nginx
你應該觀察到咩

第 4 步 Pod 總數維持 3 粒，但被你斬嗰粒個名尾碼換咗——嗰粒係 ReplicaSet 控制器幫你補返嘅新 Pod。呢個就係自我修復。同時留意 get pods 嘅 READY 同 RESTARTS 欄。

4. 實作 B：Rollout 與 Rollback（換版唔斷線、出事即回滾）

Deployment 招牌能力：換版唔使停機、出事撳個掣返轉頭。同一個叢集繼續：

🔄 Rollout 逐粒換：舊 RS 縮一粒、新 RS 大一粒

口訣：開新唔斬舊，一對一咁換；回滾唔係時光倒流，係照舊樣出多個新版。

換版本、睇歷程、回滾
# 6. image 由 nginx:1.25 換成 1.26（觸發 rollout）
kubectl set image deployment/nginx nginx=nginx:1.26

# 7. 等 rollout 完成（會印 "successfully rolled out"）
kubectl rollout status deployment/nginx

# 8. 睇歷史版本——REVISION 欄就係版號。
#    CHANGE-CAUSE 顯示 <none> 係正常（新版 kubectl 已唔用 --record）。
#    想留說明：kubectl annotate deployment/nginx kubernetes.io/change-cause="..."
kubectl rollout history deployment/nginx

# 9. 反悔，返上一版（1.25）。
#    注意：undo 之後會出「新嘅」REVISION（例如 3），唔係將 2 改返——回滾本身都係新版本
kubectl rollout undo deployment/nginx
kubectl rollout status deployment/nginx
kubectl rollout history deployment/nginx   # 再睇：多咗一行 REVISION 3

# 10. 觀察換版過程：-w = --watch，先印快照、再串流變化（新舊並存、逐批換）。
#     Ctrl+C 離開。想睇動態：開兩個 terminal，一邊跑呢行，一邊 set image 或 delete pod
kubectl get pods -w

# 11. 收工清理
kubectl delete deployment nginx
考場小抄（必背反射指令）

kubectl rollout status deployment/NAME、rollout history、rollout undo——CKA 成日考「更新 image 後確認成功」同「新版瀨嘢即回滾」，三個指令各一鍵搞掂。唔好誤判：每次 set image 或 undo 都會產生一個新 REVISION 編號（回滾＝新版本），所以 undo 之後唔係舊編號復活，而係新編號。

rollout history 對照：set image 前後 vs undo 之後
# set image 1.26 之後、undo 之前：兩個版本
deployment/nginx with revision:
  REVISION  CHANGE-CAUSE
  1         <none>        # image: nginx:1.25（初版）
  2         <none>        # image: nginx:1.26（新版）

# undo 之後：唔係返去 REVISION 1，而係出多個 REVISION 3
deployment/nginx with revision:
  REVISION  CHANGE-CAUSE
  1         <none>        # image: nginx:1.25
  2         <none>        # image: nginx:1.26
  3         <none>        # image: nginx:1.25（copy of 1，舊 image、新編號）

🧪 加料 Lab：5 秒生 Deployment YAML（CKA 真題節奏）

用考場工作流起一個 frontend-deploy（3 副本、nginx:1.25），再升上 1.26 即回滾——全程唔手寫成份 YAML：

考場指令流（目標 1 分鐘搞掂）
export do="--dry-run=client -o yaml"
kubectl create deploy frontend-deploy --image=nginx:1.25 --replicas=3 $do > dep.yaml
kubectl apply -f dep.yaml
kubectl set image deployment/frontend-deploy nginx=nginx:1.26
kubectl rollout status deployment/frontend-deploy
kubectl rollout undo deployment/frontend-deploy
kubectl delete -f dep.yaml

本課戰果

  • 你解釋到 Deployment → ReplicaSet → Pod 三層各自管咩。
  • 你親眼示範自癒：斬走一粒 Pod，控制器自動補返。
  • 你完成一次滾動更新＋一次回滾，仲用 -w 睇到換版新舊並存。
  • 你識用 $do 5 秒生 YAML，唔再逐格手打。
