# Mission: Kubernetes 從入門到 CKA 認證

## Why

自我進修 —— 已有容器經驗（Docker、YAML、Linux shell），目標是建立系統性的 Kubernetes 知識與實作能力，以 CKA 認證作為掌握程度的里程碑，而非求職壓力。

## Success looks like

- 能獨立用 kubectl / kubeadm 建置、操作、維護一個 Kubernetes 叢集
- 通過 CKA 認證考試（2 小時線上實作測驗，Kubernetes v1.35）
- 能系統化除錯：Pod、節點、控制平面、網路與儲存（Troubleshooting 佔考綱 30%）
- 五大考綱領域（架構 25%、工作負載 15%、網路 20%、儲存 10%、除錯 30%）各有可展示的實作

## Constraints

- 6 個月以上的從容節奏，不排硬性日曆進度
- 有容器經驗，不需從容器基礎教起
- 繁體中文講解 + 保留英文技術術語（CKA 考試為英文，術語必須用原文）
- Windows 本機；練習環境用 WSL2 + Docker Desktop + kind（考試是 Linux 終端機實作）
- 自我進修定位，無時程壓力

## Out of scope

- CKS / KCSA 資安認證內容
- Service Mesh、多叢集管理等高階主題
- 考試報名與付費流程（僅到應考能力水準）
